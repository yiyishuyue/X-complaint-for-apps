# X-complaint-for-apps
Skill for monitoring and analyzing complaints &amp; public opinion of competing apps. 

## Usage

Install this as a Cursor skill by copying `SKILL.md` and `templates/` into one folder Cursor loads as a skill:

- Personal: `~/.cursor/skills/x-complaint-learnings/`
- Project: `.cursor/skills/x-complaint-learnings/`

That folder should contain `SKILL.md` and `templates/report-outline.md`. Cursor picks up the skill from `SKILL.md` when a task matches it (monitoring and analyzing competing-app complaints on X/Twitter, then drafting a first-pass report from the outline).
